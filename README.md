# 🐍 Python Beginner to OOP Tutorial Repository

Repositori ini berisi kumpulan kode latihan dan dokumentasi pembelajaran dasar pemrograman Python, mulai dari sintaks dasar hingga Pemrograman Berorientasi Objek (*Object-Oriented Programming*).

## 📂 Struktur Proyek & Materi

Berikut adalah daftar modul dan file latihan yang tersedia dalam repositori ini:

| Modul / Topik | Nama File Script | Deskripsi Materi |
| :--- | :--- | :--- |
| **1. Dasar Python** | `hello.py` | Pengenalan fungsi `print()` dan eksekusi dasar via CLI. |
| **2. Variabel & Tipe Data** | `variable_numbers.py`<br>`variable_string.py`<br>`variable_boolean.py` | Deklarasi variabel, operasi angka (*integers/floats*), manipulasi *string* (*single/double/multiline quotes*), dan tipe data *Boolean*. |
| **3. Operator** | `operator_aritmatika.py`<br>`operator_comparison.py`<br>`operator_logical.py` | Operasi matematika dasar, perbandingan relasional, serta evaluasi logika (`and`, `or`, `not`). |
| **4. Control Flow** | `condition_if.py`<br>`condition_if_elif.py`<br>`condition_if_else.py` | Percabangan kondisi menggunakan `if`, `elif`, `else`, serta aturan *indentation* di Python. |
| **5. Perulangan (Loops)** | `loop_for_1.py`, `loop_for_2.py`<br>`loop_while.py`<br>`loop_for_break.py`<br>`loop_for_continue.py` | Perulangan `for` dan `while`, serta kontrol alur menggunakan `break` dan `continue`. |
| **6. Data Structures** | `lists_create.py`, `lists_add_item.py`<br>`lists_delete_item.py`, `lists_join.py`<br>`dictionaries_create.py`, etc. | Manajemen data kolektif menggunakan *Lists* dan *Dictionaries* (CRUD operations). |
| **7. Functions** | `function_create.py`<br>`function_arguments_*.py`<br>`function_default_value_arguments.py` | Pembuatan fungsi, *positional/keyword arguments*, `*args`, `**kwargs`, dan *default parameters*. |
| **8. OOP (Class & Object)** | `class_create.py`<br>`class_method_constructor.py`<br>`class_self_parameter.py` | Pembuatan *Class*, instansiasi objek, *constructor* `__init__`, *methods*, dan parameter `self`. |
